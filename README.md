# Mobility Gap AI (名古屋市 交通空白地帯・移動格差分析)

名古屋都市圏における「公共交通アクセスの空白」と「高齢化・人口動態」を掛け合わせ、真に支援が必要な**交通弱者・移動困難地域（Mobility Gap）**をデータドリブンに可視化・分析するプロジェクトです。

---

## 📊 分析サマリー（名古屋都市圏）

国勢調査（令和2年）500mメッシュと、名古屋市交通局バス停、国土数値情報鉄道データを突合した分析結果：

* **対象地域総人口**: 約 3,484,000 人（うち65歳以上: 約 835,000 人）
* **公共交通空白地帯の人口**: 約 **735,000 人**（全体の **21.1%**）
* **公共交通空白地帯の高齢者**: 約 **178,000 人**（高齢者全体の **21.3%**）
* **深刻な高リスク地域（バス停・駅ともに800m以上離隔）**: **629 メッシュ**

## 🧮 移動格差指数（Mobility Gap Score）の算出手法

各500mメッシュ（JIS X 0410 4次メッシュ）の中心点から、以下の指標を計算しています。

1. **交通アクセス距離の算出**:
   * 最寄りバス停留所までの直線距離 $d_{\text{bus}}$ (m)
   * 最寄り鉄道駅までの直線距離 $d_{\text{station}}$ (m)
2. **交通空白地帯（Transit Desert）の判定**:
   * バス停徒歩5分（400m）超 かつ 駅徒歩10分（800m）超のエリアを交通空白と定義。
3. **リスクレベル分類**:
   * **Level 0 (良好)**: バス停400m以内 または 駅800m以内
   * **Level 1 (注意)**: バス停400〜600m、駅800m超
   * **Level 2 (交通空白)**: バス停600〜800m、駅800m超
   * **Level 3 (深刻な交通空白地帯)**: バス停・駅ともに800m超（徒歩10分以上）
4. **移動格差指数（Mobility Gap Index）**:
   $$\text{GapScore} = \text{高齢者人口} \times \left(\frac{d_{\text{bus}}}{400} \times \frac{d_{\text{station}}}{800}\right)$$

## 🚀 ダッシュボードの起動方法

1. ターミナルで本ディレクトリへ移動:
   ```bash
   cd mobility-gap-ai
   ```
2. ローカルサーバーを起動:
   ```bash
   python -m http.server 8000
   ```
3. ブラウザでアクセス:
   [http://localhost:8000](http://localhost:8000)
