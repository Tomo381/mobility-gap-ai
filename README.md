# Mobility Gap AI

> **「誰もが自由に移動できる社会を、データの力で実現する。」**

Mobility Gap AI は、愛知県および東海圏における「交通空白地帯」を可視化・分析し、デマンド交通導入に向けた政策提言を支援するWebアプリケーションです。

少子高齢化、公共交通の減便・廃止、運転免許返納者の増加などにより、日本各地で移動困難地域（Mobility Gap）が拡大しています。本プロジェクトでは、公共交通オープンデータ、人口統計データ、地理空間データを統合し、交通サービスの不足地域を定量的に評価します。

## 📊 愛知県全域における実証分析サマリー (鉄道ダイヤ運行頻度加味)

国勢調査（令和2年）500mメッシュ（12,336メッシュ）と、国土数値情報バス停留所データ（P11・9,121箇所）、国土数値情報鉄道データ（N02・774駅）、および独自整備した鉄道運行頻度マスター（全62路線ルール）を突合した分析結果：

* **対象地域総人口**: 約 **7,542,000 人**（うち65歳以上: 約 **1,865,000 人**）
* **深刻な高リスク地域（最優先対策 / 赤色）**: **64 メッシュ**（高齢者 約 **6,864 人**）
* **交通空白地帯（要改善 / 橙色＋赤色）**: **408 メッシュ**（高齢者 約 **68,187 人**）
* **公共交通網**: バス停留所 **9,121 箇所** / 鉄道駅 **774 駅**（超高頻度 22駅、高頻度 326駅、標準 244駅、やや低頻度 87駅、極めて低頻度 95駅）

> **💡 ダイヤ頻度加味による洞察**:
> 単なる物理距離の評価から「運行頻度（ダイヤ間隔）」を加味した結果、駅から近いものの昼間本数が1時間に1本以下しかないローカル線沿線（JR飯田線北部、名鉄蒲郡線・知多新線、城北線等）が交通空白地帯・深刻地域として正当にあぶり出され、深刻・空白エリアが従来の204箇所から408箇所へと倍増しました。

## 🧮 Mobility Gap 指数（新・MGS）の算出定義

各500mメッシュ（JIS X 0410 4次メッシュ）の中心点から、以下の計算式に基づき **Mobility Gap Score（MGS）** を算出しています。

### 【新・算出式】
$$\text{MGS} = \text{高齢者人口} \times \left(\frac{d_{\text{bus}}}{400\text{m}}\right) \times \left(\frac{d_{\text{station}}}{800\text{m}} \times \mathbf{F_{\text{train}}}\right)$$

* **$d_{\text{bus}}$**: 最寄りバス停留所までの直線距離 (m) [基準徒歩圏: 400m / 徒歩約5分]
* **$d_{\text{station}}$**: 最寄り鉄道駅までの直線距離 (m) [基準徒歩圏: 800m / 徒歩約10分]
* **$\mathbf{F_{\text{train}}}$**: **鉄道運行頻度ペナルティ係数**（昼間運行本数に応じた重み付け）
* **高齢者人口**: 各500mメッシュ内の65歳以上人口（国勢調査）

### 【鉄道運行頻度係数（$F_{\text{train}}$）の基準】

| 運行水準 | 平日昼間本数 | 平均間隔 | 該当路線の例 | 頻度係数 ($F_{\text{train}}$) | 愛知県周辺駅数 |
| :---: | :---: | :---: | :---| :---: | :---: |
| **超高頻度** | **12本/時** | 約5分 | 地下鉄東山線 | **1.00倍** (快適・時刻表不要) | 22 駅 |
| **高頻度** | **6〜8本/時** | 約7.5〜10分 | 地下鉄名城/桜通/鶴舞線、JR東海道線/中央線、名鉄名古屋本線/犬山線 | **1.05〜1.15倍** (高利便性) | 326 駅 |
| **標準** | **4本/時** | 約15分 | 名鉄三河/瀬戸/小牧/豊田線、あおなみ線、愛環、豊鉄渥美線 | **1.25〜1.35倍** (15分ヘッドウェイ) | 244 駅 |
| **やや低頻度** | **2〜3本/時** | 約20〜30分 | 名鉄西尾/尾西/知多新/蒲郡線、JR武豊線/関西線、JR飯田線南部 | **1.45〜1.85倍** (時刻確認が必要) | 87 駅 |
| **極めて低頻度** | **1本/時以下** | 60分以上 | JR飯田線北部（本長篠以北）、城北線、天浜線、養老線、明知線 | **2.20〜3.50倍** (1本逃すと致命的) | 95 駅 |

## 🎨 5段階リスクレベル・カラー定義

深刻度が低い順から高い順へ、直感的な5段階グラデーションで分類・可視化しています：

| レベル | 表示色 | 深刻度・区分 | 判定基準 (MGS) | 愛知県全域メッシュ数 | 高齢者人口 |
|:---:|:---:|:---|:---|:---:|:---:|
| **Level 1** | 🟦 **青** | **極めて良好（至便）** | $\text{MGS} < 200$ | 7,293 件 (59.1%) | 790,580 人 |
| **Level 2** | 🟩 **黄緑** | **良好（軽微）** | $200 \le \text{MGS} < 600$ | 3,357 件 (27.2%) | 716,967 人 |
| **Level 3** | 🟨 **黄色** | **注意（交通不便）** | $600 \le \text{MGS} < 1,500$ | 1,278 件 (10.4%) | 288,869 人 |
| **Level 4** | 🟧 **橙色** | **交通空白地帯（要改善）** | $1,500 \le \text{MGS} < 4,000$ | 344 件 (2.8%) | 61,323 人 |
| **Level 5** | 🟥 **赤色** | **深刻な交通空白（最優先対策）** | $\text{MGS} \ge 4,000$ | **64 件 (0.5%)** | **6,864 人** |

## 🚀 ダッシュボードの起動方法

1. リポジトリをクローンまたはローカルへ移動:
   ```bash
   cd mobility-gap-ai
   ```
2. 依存ライブラリのインストール（前処理スクリプト実行時のみ必要）:
   ```bash
   pip install -r requirements.txt
   ```
3. 簡易Webサーバーを起動:
   ```bash
   python -m http.server 8000
   ```
4. ブラウザでアクセス:
   [http://localhost:8000](http://localhost:8000)
