# Mobility Gap AI

> **「誰もが自由に移動できる社会を、データの力で実現する。」**

Mobility Gap AI は、愛知県および東海圏における「交通空白地帯」を可視化・分析し、デマンド交通導入に向けた政策提言を支援するWebアプリケーションです。

少子高齢化、公共交通の減便・廃止、運転免許返納者の増加などにより、日本各地で移動困難地域（Mobility Gap）が拡大しています。本プロジェクトでは、公共交通オープンデータ、人口統計データ、地理空間データを統合し、交通サービスの不足地域を定量的に評価します。

* **深刻な高リスク地域（最優先対策 / 赤色）**: **245 メッシュ**（高齢者 約 **29,830 人**）
* **交通空白地帯（要改善 / 橙色＋赤色）**: **1,092 メッシュ**（高齢者 約 **178,966 人**）
* **【NEW】交通空白 × 買い物難民 重複エリア**: **819 メッシュ**（高齢者 約 **87,374 人**）
  * 公共交通が不便（Lv4/Lv5）かつ最寄りスーパーマーケットまで 1km 以上（徒歩15分超）離れた、日常の食料品調達が極めて困難な地域。デマンド交通や移動販売車の最優先導入候補。
* **【NEW】医療アクセス困難地域（病院/診療所 ≥ 1.5km）**: **2,716 メッシュ**（高齢者 約 **38,457 人**）
* **公共交通＆生活インフラ網**: 
  * バス停留所 **9,121 箇所**（実GTFSダイヤ反映: 1,593箇所、系統推計マスター反映: 7,528箇所）
  * 鉄道駅 **774 駅**（超高頻度 22駅、高頻度 326駅、標準 244駅、やや低頻度 87駅、極めて低頻度 95駅）

## 🧮 Mobility Gap 指数（新・MGS W頻度統合版）の算出定義

各500mメッシュ（JIS X 0410 4次メッシュ）の中心点から、以下の計算式に基づき **Mobility Gap Score（MGS）** を算出しています。

### 【新・算出式】
$$\text{MGS} = \text{高齢者人口} \times \left(\frac{d_{\text{bus}}}{400\text{m}} \times \mathbf{F_{\text{bus}}}\right) \times \left(\frac{d_{\text{station}}}{800\text{m}} \times \mathbf{F_{\text{train}}}\right)$$

* **$d_{\text{bus}}$**: 最寄りバス停留所までの直線距離 (m) [基準徒歩圏: 400m / 徒歩約5分]
* **$\mathbf{F_{\text{bus}}}$**: **バス運行頻度ペナルティ係数**（実GTFSダイヤ本数および系統推計マスターに応じた重み付け）
* **$d_{\text{station}}$**: 最寄り鉄道駅までの直線距離 (m) [基準徒歩圏: 800m / 徒歩約10分]
* **$\mathbf{F_{\text{train}}}$**: **鉄道運行頻度ペナルティ係数**（昼間運行本数に応じた重み付け）
* **高齢者人口**: 各500mメッシュ内の65歳以上人口（国勢調査）

---

### 【バス運行頻度係数（$F_{\text{bus}}$）の基準】

| 運行水準 | 平日昼間本数 | 平均間隔 | 該当路線の例・データソース | 頻度係数 ($F_{\text{bus}}$) | 愛知県内バス停数 |
| :---: | :---: | :---: | :---| :---: | :---: |
| **高頻度** | **4本以上/時** | 15分未満 | 名古屋市営バス主要幹線（実GTFS）、名鉄バス主要ターミナル（4系統以上） | **1.00倍** (快適・ストレスなし) | 1,624 箇所 (17.8%) |
| **標準** | **2〜3本/時** | 20〜30分 | 名市バス中頻度線（実GTFS）、名鉄・豊鉄一般主要幹線、とよたおいでんバス幹線 | **1.10〜1.40倍** (普通・実用水準) | 1,586 箇所 (17.4%) |
| **やや低頻度** | **1〜1.5本/時** | 40〜60分 | 郊外単独系統路線、都市部コミュニティバス巡回路線（日進、一宮、春日井等） | **1.70〜2.00倍** (時刻表確認が必須) | 4,606 箇所 (50.5%) |
| **低頻度** | **0.5〜0.6本/時** | 100〜120分 | 半島・沿岸・地方コミュニティバス（南知多、田原ぐるりん、新城Sバス等） | **2.60〜2.80倍** (1本逃すと致命的) | 1,047 箇所 (11.5%) |
| **極めて低頻度** | **1日数便以下** | 240分以上 | 奥三河過疎町村営バス（設楽・東栄・豊根）、新城市山間部末端路線 | **3.50〜3.80倍** (交通空白地帯と同等) | 258 箇所 (2.8%) |

### 【鉄道運行頻度係数（$F_{\text{train}}$）の基準】

| 運行水準 | 平日昼間本数 | 平均間隔 | 該当路線の例 | 頻度係数 ($F_{\text{train}}$) | 愛知県周辺駅数 |
| :---: | :---: | :---: | :---| :---: | :---: |
| **超高頻度** | **12本/時** | 約5分 | 地下鉄東山線 | **1.00倍** (快適・時刻表不要) | 22 駅 |
| **高頻度** | **6〜8本/時** | 約7.5〜10分 | 地下鉄名城/桜通/鶴舞線、JR東海道線/中央線、名鉄名古屋本線/犬山線 | **1.05〜1.15倍** (高利便性) | 326 駅 |
| **標準** | **4本/時** | 約15分 | 名鉄三河/瀬戸/小牧/豊田線、あおなみ線、愛環、豊鉄渥美線 | **1.25〜1.35倍** (15分ヘッドウェイ) | 244 駅 |
| **やや低頻度** | **2〜3本/時** | 約20〜30分 | 名鉄西尾/尾西/知多新/蒲郡線、JR武豊線/関西線、JR飯田線南部 | **1.45〜1.85倍** (時刻確認が必要) | 87 駅 |
| **極めて低頻度** | **1本/時以下** | 60分以上 | JR飯田線北部（本長篠以北）、城北線、天浜線、養老線、明知線 | **2.20〜3.50倍** (1本逃すと致命的) | 95 駅 |

## 🎨 5段階リスクレベル・カラー定義

深刻度が低い順から高い順へ、直感的な5段階グラデーションで分類・可視化しています：

| レベル | 表示色 | 深刻度・区分 | 判定基準 (MGS) | 愛知県全域メッシュ数 | 高齢者人口 |
|:---:|:---:|:---|:---|:---:|:---:|
| **Level 1** | 🟦 **青** | **極めて良好（至便）** | $\text{MGS} < 200$ | 5,365 件 (43.5%) | 534,373 人 |
| **Level 2** | 🟩 **黄緑** | **良好（軽微）** | $200 \le \text{MGS} < 600$ | 3,792 件 (30.7%) | 716,387 人 |
| **Level 3** | 🟨 **黄色** | **注意（交通不便）** | $600 \le \text{MGS} < 1,500$ | 2,087 件 (16.9%) | 434,877 人 |
| **Level 4** | 🟧 **橙色** | **交通空白地帯（要改善）** | $1,500 \le \text{MGS} < 4,000$ | 847 件 (6.9%) | 149,136 人 |
| **Level 5** | 🟥 **赤色** | **深刻な交通空白（最優先対策）** | $\text{MGS} \ge 4,000$ | **245 件 (2.0%)** | **29,830 人** |

## 🚀 ダッシュボードの起動方法

1. リポジトリをクローンまたはローカルへ移動:
   ```bash
   cd mobility-gap-ai
   ```
2. 依存ライブラリのインストール（前処理スクリプト実行時のみ必要）:
   ```bash
   pip install -r requirements.txt
   ```
3. 簡易Webサーバーを起動:
   ```bash
   python -m http.server 8000
   ```
4. ブラウザでアクセス:
   [http://localhost:8000](http://localhost:8000)
