# Mobility Gap AI

> **「誰もが自由に移動できる社会を、データの力で実現する。」**

Mobility Gap AI は、愛知県および東海圏における「交通空白地帯」を可視化・分析し、デマンド交通導入に向けた政策提言を支援するWebアプリケーションです。

少子高齢化、公共交通の減便・廃止、運転免許返納者の増加などにより、日本各地で移動困難地域（Mobility Gap）が拡大しています。本プロジェクトでは、公共交通オープンデータ、人口統計データ、地理空間データを統合し、交通サービスの不足地域を定量的に評価します。

## 📊 名古屋都市圏における実証分析サマリー (Phase 1 実装完了)

国勢調査（令和2年）500mメッシュと、名古屋市交通局バス停（3,886箇所）、国土数値情報鉄道データ（242駅）を突合した分析結果：

* **対象地域総人口**: 約 **3,484,000 人**（うち65歳以上: 約 835,000 人）
* **公共交通空白地帯の人口**: 約 **735,000 人**（全体の **21.1%**）
* **公共交通空白地帯の高齢者**: 約 **178,000 人**（高齢者全体の **21.3%**）
* **深刻な高リスク地域（バス停・駅ともに800m以上離隔）**: **629 メッシュ**

## 🧮 移動格差指数（Mobility Gap Score: MGS）の算出手法

各500mメッシュ（JIS X 0410 4次メッシュ）の中心点から、以下の指標を計算しています。

1. **交通アクセス距離の算出**:
   * 最寄りバス停留所までの直線距離 $d_{\text{bus}}$ (m)
   * 最寄り鉄道駅までの直線距離 $d_{\text{station}}$ (m)
2. **交通空白地帯（Transit Desert）の判定**:
   * バス停徒歩5分（400m）超 かつ 駅徒歩10分（800m）超のエリアを交通空白と定義。
3. **リスクレベル分類**:
   * **Level 0 (良好)**: バス停400m以内 または 駅800m以内
   * **Level 1 (注意)**: バス停400〜600m、駅800m超
   * **Level 2 (交通空白)**: バス停600〜800m、駅800m超
   * **Level 3 (深刻な交通空白地帯)**: バス停・駅ともに800m超（徒歩10分以上）
4. **移動格差指数（Mobility Gap Score）**:
   $$\text{MGS} = \text{高齢者人口} \times \left(\frac{d_{\text{bus}}}{400} \times \frac{d_{\text{station}}}{800}\right)$$

## 🗂️ プロジェクト構成

```text
mobility-gap-ai/
├── process_data.py               # データ前処理・JISメッシュ生成・Mobility Gap算出パイプライン

├── script/
│   └── convert_geojson.py       # GTFSデータ変換スクリプト
└── data/
    ├── Nagoya_bus_stop.text      # 名古屋市交通局バス停留所データ (GTFS形式 3,886件)
    ├── tblT001101H23.txt         # 令和2年国勢調査 500mメッシュ男女・年齢別人口 (愛知県)
    ├── nagoya_stations.geojson   # 抽出・軽量化した名古屋都市圏鉄道駅データ (242駅)
    ├── nagoya_mobility_gap_mesh.geojson # 算出した移動格差500mメッシュデータ
    ├── summary_metrics.json      # 分析指標サマリー
    └── N02-20_GML/               # 国土数値情報（全国鉄道データ原本）
```

## 🎯 主な機能と実装状況

* [x] **バス停・鉄道駅可視化機能**: GTFS・国土数値情報から停留所・駅を地図上にプロット
* [x] **Mobility Gap Score (MGS) 計算**: 500mメッシュごとの交通利便性・高齢化率の統合評価
* [x] **ヒートマップ表示**: 交通空白リスクに応じたカラーメッシュ描画（赤/橙/黄/灰）
* [x] **地域詳細分析パネル**: メッシュクリック時の人口・高齢者数・交通離隔距離・Gap指数の即時表示
* [ ] **AI提言機能 (Phase 4)**: 分析結果をもとに生成AIが最適な交通施策（デマンド交通、病院送迎など）を自動提案
* [ ] **デマンド交通シミュレーション (Phase 5)**: 新規停留所設置やオンデマンド便導入による移動困難人口の改善効果予測
