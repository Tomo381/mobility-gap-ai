# Mobility Gap AI

> **「誰もが自由に移動できる社会を、データの力で実現する。」**

Mobility Gap AI は、愛知県および東海圏における「交通空白地帯」を可視化・分析し、デマンド交通導入に向けた政策提言を支援するWebアプリケーションです。

少子高齢化、公共交通の減便・廃止、運転免許返納者の増加などにより、日本各地で移動困難地域（Mobility Gap）が拡大しています。本プロジェクトでは、公共交通オープンデータ、人口統計データ、地理空間データを統合し、交通サービスの不足地域を定量的に評価します。

## 📊 名古屋都市圏における実証分析サマリー (Phase 1 実装完了)

国勢調査（令和2年）500mメッシュと、名古屋市交通局バス停（3,886箇所）、国土数値情報鉄道データ（242駅）を突合した分析結果：

* **対象地域総人口**: 約 **3,484,000 人**（うち65歳以上: 約 835,000 人）
* **深刻な高リスク地域（最優先対策 / 赤色）**: **188 メッシュ**（高齢者 約 **62,000 人**）
* **交通空白地帯（要改善 / 橙色＋赤色）**: **558 メッシュ**（高齢者 約 **158,000 人**）
* **公共交通網**: バス停留所 3,886 箇所 / 鉄道駅 242 駅

## 🧮 Mobility Gap 指数（MGS）の算出定義

各500mメッシュ（JIS X 0410 4次メッシュ）の中心点から、以下の計算式に基づき **Mobility Gap Score（MGS）** を算出しています。

### 【算出式】
$$\text{MGS} = \text{高齢者人口} \times \left(\frac{d_{\text{bus}}}{400\text{m}}\right) \times \left(\frac{d_{\text{station}}}{800\text{m}}\right)$$

* **$d_{\text{bus}}$**: 最寄りバス停留所までの直線距離 (m) [基準徒歩圏: 400m / 徒歩約5分]
* **$d_{\text{station}}$**: 最寄り鉄道駅までの直線距離 (m) [基準徒歩圏: 800m / 徒歩約10分]
* **高齢者人口**: 各500mメッシュ内の65歳以上人口（国勢調査）
* **係数の意味**:
  * $d_{\text{bus}} / 400\text{m}$ : バス停アクセスペナルティ（400mで1.0、800mで2.0、1,200mで3.0倍）
  * $d_{\text{station}} / 800\text{m}$ : 鉄道駅アクセスペナルティ（800mで1.0、1,600mで2.0倍）

## 🎨 5段階リスクレベル・カラー定義

深刻度が低い順から高い順へ、直感的な5段階グラデーションで分類・可視化しています：

| レベル | 表示色 | 深刻度・区分 | 判定基準 (MGS) | 対象メッシュ数 | 高齢者人口 |
|:---:|:---:|:---|:---|:---:|:---:|
| **Level 1** | 🟦 **青** | **極めて良好（至便）** | $\text{MGS} < 200$ | 909 件 (37.1%) | 324,916 人 |
| **Level 2** | 🟩 **黄緑** | **良好（軽微）** | $200 \le \text{MGS} < 600$ | 571 件 (23.3%) | 229,327 人 |
| **Level 3** | 🟨 **黄色** | **注意（交通不便）** | $600 \le \text{MGS} < 1,500$ | 410 件 (16.7%) | 122,283 人 |
| **Level 4** | 🟧 **橙色** | **交通空白地帯（要改善）** | $1,500 \le \text{MGS} < 4,000$ | 370 件 (15.1%) | 95,868 人 |
| **Level 5** | 🟥 **赤色** | **深刻な交通空白（最優先対策）** | $\text{MGS} \ge 4,000$ | **188 件 (7.7%)** | **62,196 人** |

> **基準引き上げのポイント**:
> 従来の「バス・駅800m超」による一律判定（848件）から、MGS $\ge 4,000$（上位7.7%）を「深刻（赤色）」とする厳格な基準へ引き上げ、真に緊急性の高い最優先地域をピンポイントで特定できるように改善しました。

## 🚀 ダッシュボードの起動方法

1. リポジトリをクローンまたはローカルへ移動:
   ```bash
   cd mobility-gap-ai
   ```
2. 簡易Webサーバーを起動:
   ```bash
   python -m http.server 8000
   ```
3. ブラウザでアクセス:
   [http://localhost:8000](http://localhost:8000)
