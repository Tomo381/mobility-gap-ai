# Mobility Gap AI

> **「誰もが自由に移動できる社会を、データの力で実現する。」**

Mobility Gap AI は、愛知県および東海圏における「交通空白地帯」を可視化・分析し、デマンド交通導入に向けた政策提言を支援するWebアプリケーションです。

少子高齢化、公共交通の減便・廃止、運転免許返納者の増加などにより、日本各地で移動困難地域（Mobility Gap）が拡大しています。本プロジェクトでは、公共交通オープンデータ、人口統計データ、地理空間データを統合し、交通サービスの不足地域を定量的に評価します。

国勢調査（令和2年）500mメッシュ（12,336メッシュ）と、国土数値情報バス停留所データ（P11・9,121箇所）、国土数値情報鉄道データ（N02・774駅）を突合した分析結果：

* **対象地域総人口**: 約 **7,542,000 人**（うち65歳以上: 約 **1,865,000 人**）
* **深刻な高リスク地域（最優先対策 / 赤色）**: **32 メッシュ**（高齢者 約 **4,412 人**）
* **交通空白地帯（要改善 / 橙色＋赤色）**: **204 メッシュ**（高齢者 約 **39,367 人**）
* **公共交通網**: バス停留所 **9,121 箇所**（名鉄バス・豊鉄バス・知多バス・名古屋市バス・各市町村コミュニティバス等） / 鉄道駅 **774 駅**

## 🧮 Mobility Gap 指数（MGS）の算出定義

各500mメッシュ（JIS X 0410 4次メッシュ）の中心点から、以下の計算式に基づき **Mobility Gap Score（MGS）** を算出しています。

### 【算出式】
$$\text{MGS} = \text{高齢者人口} \times \left(\frac{d_{\text{bus}}}{400\text{m}}\right) \times \left(\frac{d_{\text{station}}}{800\text{m}}\right)$$

* **$d_{\text{bus}}$**: 最寄りバス停留所までの直線距離 (m) [基準徒歩圏: 400m / 徒歩約5分]
* **$d_{\text{station}}$**: 最寄り鉄道駅までの直線距離 (m) [基準徒歩圏: 800m / 徒歩約10分]
* **高齢者人口**: 各500mメッシュ内の65歳以上人口（国勢調査）
* **係数の意味**:
  * $d_{\text{bus}} / 400\text{m}$ : バス停アクセスペナルティ（400mで1.0、800mで2.0、1,200mで3.0倍）
  * $d_{\text{station}} / 800\text{m}$ : 鉄道駅アクセスペナルティ（800mで1.0、1,600mで2.0倍）

## 🎨 5段階リスクレベル・カラー定義

深刻度が低い順から高い順へ、直感的な5段階グラデーションで分類・可視化しています：

| レベル | 表示色 | 深刻度・区分 | 判定基準 (MGS) | 愛知県全域メッシュ数 | 高齢者人口 |
|:---:|:---:|:---|:---|:---:|:---:|
| **Level 1** | 🟦 **青** | **極めて良好（至便）** | $\text{MGS} < 200$ | 8,327 件 (67.5%) | 931,576 人 |
| **Level 2** | 🟩 **黄緑** | **良好（軽微）** | $200 \le \text{MGS} < 600$ | 2,933 件 (23.8%) | 674,985 人 |
| **Level 3** | 🟨 **黄色** | **注意（交通不便）** | $600 \le \text{MGS} < 1,500$ | 872 件 (7.1%) | 218,675 人 |
| **Level 4** | 🟧 **橙色** | **交通空白地帯（要改善）** | $1,500 \le \text{MGS} < 4,000$ | 172 件 (1.4%) | 34,955 人 |
| **Level 5** | 🟥 **赤色** | **深刻な交通空白（最優先対策）** | $\text{MGS} \ge 4,000$ | **32 件 (0.3%)** | **4,412 人** |

## 🚀 ダッシュボードの起動方法

1. リポジトリをクローンまたはローカルへ移動:
   ```bash
   cd mobility-gap-ai
   ```
2. 依存ライブラリのインストール（前処理スクリプト実行時のみ必要）:
   ```bash
   pip install -r requirements.txt
   ```
3. 簡易Webサーバーを起動:
   ```bash
   python -m http.server 8000
   ```
4. ブラウザでアクセス:
   [http://localhost:8000](http://localhost:8000)
